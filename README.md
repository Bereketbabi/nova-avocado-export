# Nova Wholesale Trade — Ethiopian Agricultural Export Showcase

A high-performance modern web application showcasing Ethiopian agricultural exports (premium bananas and avocados), built with TanStack Start, React 19, and Tailwind CSS.

## Key Features

- **Cinematic Brand Experience**: Motion-rich intro preloader and page transitions featuring the Nova emblem.
- **Authentic Agricultural Showcase**: High-resolution imagery of Ethiopian farms, harvesting, quality inspection, and packaging.
- **Export Catalog & Specifications**: Detailed product specs, caliber, packaging, and cold-chain supply capabilities.
- **Trade Inquiry Portal**: Direct inquiry channel with comprehensive Zod form validation and direct communication links.
- **Full Responsiveness**: Adaptive layouts optimized for mobile, tablet, and widescreen desktop displays.

## Tech Stack

- **Framework**: TanStack Start (SSR full-stack framework on Vite and Nitro)
- **Routing**: TanStack Router (File-based, type-safe routing)
- **UI / Styling**: React 19, Tailwind CSS v4, Lucide Icons
- **Animation**: Framer Motion
- **Validation**: Zod & React Hook Form
- **Data Layer**: TanStack Query

## Local Development

Ensure Node.js (v20+) is installed.

```sh
npm install
npm run dev
```

Build for production:

```sh
npm run build
npm run preview
```
